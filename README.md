# Lovely System Pledge

Pledge begins without a voice. It asks a visitor to lend one, admits the visitor after validating the audio envelope, evaluates the contribution asynchronously, and uses accepted time-bound recordings to ask future visitors:

> Who are you?

## Current state

Pledge has no deployed application and no executable implementation in this
branch. The first implementation was deliberately removed after review. The
project will be rebuilt from the preserved specification in smaller,
independently reviewable increments.
